# BTC-USD

The site is configured to deploy from [`IPDA-Desk-BTC-USD/`](IPDA-Desk-BTC-USD/) and the repository root publish artifact.

- **Live terminal:** https://becomingaman2000-ship-it.github.io/BTC-USD/
- **Source and local run instructions:** [`IPDA-Desk-BTC-USD/README.md`](IPDA-Desk-BTC-USD/README.md)

The repository root contains the complete static publish artifact mirrored from `IPDA-Desk-BTC-USD/public`. This keeps the configured legacy GitHub Pages source pointed at the correct `index.html`, so the project-page URL resolves its HTML, JavaScript modules, stylesheets, chart data, favicon, and backtest page from one consistent root.
